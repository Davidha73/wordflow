        What's New in WordFlow v0.2.0
        
      

      

        
Here's a summary of what's been added since v0.1.0:

        
    
          
  • Auto-Save & Status Indicator: Turn on automatic saving (30s, 1m, or 5m) in Settings and see live Auto-Save status in the bottom bar.
    • 
          
  • Expanded Document Menu: Open recent files, start from a template, duplicate, rename, revert to saved, reveal in Finder, or save any document as a reusable template.
    • 
          
  • Start Screen Upgrades: Pick a document mode directly from the New Document split button, browse 4 templates or 5 recent documents at a glance, and click More… to view everything.
    • 
          
  • Writing & Proofing Controls: Toggle Spellcheck and Grammar checks independently, and review or remove words in your Custom Dictionary.
    • 
          
  • Document Defaults & Workspace: Set default line spacing, page margins, measurement units, and System (Auto) theme, or reset toolbars and the Inspector layout in one click.
    • 
          
  • Native Print & PDF: Fixed Print / Export as PDF on macOS to open the system print & PDF dialog directly.
